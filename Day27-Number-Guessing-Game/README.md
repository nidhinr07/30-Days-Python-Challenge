# Day 27 - Number Guessing Game 🎮🐍

## Introduction

On the twenty-seventh day of my Python learning journey, I decided to practice Python by building a simple **Number Guessing Game**.

Instead of learning a new topic, I focused on applying the Python concepts I have already learned to a small game.

The game will be developed step by step through four commits.

---

# Game

## Number Guessing Game

The computer generates a random number, and the player has to guess the number.

The game will gradually include:

- Random number generation
- User guesses
- Limited attempts
- Hints
- Score system
- Difficulty levels
- Replay option
- Exception handling

---

# Commit 1 - Basic Guessing Game

The first version allows the computer to:

- Generate a random number
- Ask the player to guess the number
- Check whether the guess is correct
- Continue until the correct number is found

---

# Commit 2 - Attempts and Hints

The second version adds:

- Limited attempts
- "Too high" hint
- "Too low" hint
- Game over message

---

# Commit 3 - Score and Difficulty

The third version adds:

- Easy difficulty

- Score calculation
