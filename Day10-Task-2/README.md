# Day 10 - Python Practice Problems 🐍

## Introduction

After learning the basic Python concepts from Day 1 to Day 9, I created two practice problems to revise and combine the concepts learned so far.

These problems focus on writing programs using basic Python concepts instead of introducing new topics.

---

# Problem 01 - Student Report

Create a program that accepts details of multiple students and generates a simple report.

### Requirements

- Store student details using a dictionary.
- Store multiple students using a list.
- Ask for the student's name, age, and marks.
- Use a function to calculate the result.
- Use `if-else` to determine Pass or Fail.
- Use a loop to process multiple students.
- Handle invalid marks using exception handling.
- Display the final student report.

### Concepts Practiced

- Data Types
- Strings
- Lists
- Dictionaries
- Loops
- Functions
- `if-else`
- Exception Handling

---

# Problem 02 - Expense Tracker

Create a simple expense tracker that allows the user to enter and manage their expenses.

### Requirements

- Store expenses using a dictionary.
- Store multiple expenses using a list.
- Create functions for adding and displaying expenses.
- Use a loop to display all expenses.
- Calculate the total expense.
- Use a module such as `math` for a simple calculation.
- Handle invalid amount input using exception handling.
- Use recursion to display a simple summary or count the expenses.

### Concepts Practiced

- Lists
- Tuples
- Dictionaries
- Strings
- Loops
- Functions
- Recursion
- Modules
- Exception Handling

The goal of these two problems is to revise the Python concepts learned during the first nine days and practice combining multiple concepts to solve simple real-world problems.
