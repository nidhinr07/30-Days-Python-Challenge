# Day 26 - Student Management System 🎓

## Introduction

On the twenty-sixth day of my Python learning journey, I continued practicing Python by building a simple **Student Management System**.

Instead of learning a new topic, I focused on applying the Python concepts I have already learned to a practical project.

The project will be developed step by step through four commits.

---

# Project

## Student Management System

The program allows the user to manage student information.

The project will gradually include:

- Adding students
- Viewing students
- Searching for students
- Updating student information
- Deleting students
- File handling
- Exception handling
- Input validation
- Menu-driven programming

---

# Commit 1 - Basic Student Management

The first version allows the user to:

- Add a student
- View students
- Exit the program

Student information is stored temporarily in a dictionary.

---

# Commit 2 - Search, Update and Delete

The second version adds:

- Search for a student
- Update student information
- Delete a student

---

# Commit 3 - File Handling

The third version adds file handling.

The program can:

- Save student information to a file
- Load saved students
- Keep student information available after restarting the program

---

# Commit 4 - Exception Handling and Final Improvements

The final version adds:

- Exception handling
- Input validation
- Better menu structure
- Cleaner functions
- Improved student management
