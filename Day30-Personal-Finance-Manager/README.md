# Day 30 - Personal Finance Manager 💰🐍

## Introduction

On the thirtieth day of my Python learning journey, I completed my **30-Day Python GitHub Challenge** by building a simple **Personal Finance Manager**.

This project combines many of the Python concepts I learned throughout the challenge into one practical application.

The project will be developed step by step through four commits.

---

# Project

## Personal Finance Manager

The Personal Finance Manager allows the user to keep track of income and expenses.

The project will gradually include:

- Adding income
- Adding expenses
- Viewing financial records
- Searching records
- Calculating balance
- Deleting records
- File handling
- Exception handling
- Input validation
- Menu-driven programming

---

# Commit 1 - Add Income, Add Expense and View Records

The first version allows the user to:

- Add income
- Add an expense
- View all financial records
- Exit the program

The records are stored temporarily in a list.

---

# Commit 2 - Search, Delete and Calculate Balance

The second version adds:

- Search records
- Delete records
- Calculate total income
- Calculate total expenses
- Calculate current balance

---

# Commit 3 - File Handling

The third version adds file handling.

The program can:

- Save financial records to a file
- Load saved records when the program starts
- Keep records after closing the program

---

# Commit 4 - Exception Handling and Final Improvements

The final version adds:

- Exception handling
- Input validation
- Prevent invalid amounts
- Better menu structure
- Cleaner functions
- Improved record management
