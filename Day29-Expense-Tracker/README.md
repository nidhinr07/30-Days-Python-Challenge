## Introduction

On the twenty-ninth day of my Python learning journey, I continued practicing Python by building a simple **Expense Tracker**.

Instead of learning a new Python topic, I focused on applying the Python concepts I have already learned to a practical project.

The project will be developed step by step through four commits.

---

# Project

## Expense Tracker

The Expense Tracker allows the user to record and manage daily expenses.

The project will gradually include:

- Adding expenses
- Viewing expenses
- Searching expenses
- Deleting expenses
- Calculating total expenses
- File handling
- Exception handling
- Input validation
- Menu-driven programming

---

# Commit 1 - Add and View Expenses

The first version allows the user to:

- Add an expense
- View all expenses
- Exit the program

The expenses are stored temporarily in a list.

---

# Commit 2 - Search, Delete and Calculate Total

The second version adds:

- Search for an expense
- Delete an expense
- Calculate total expenses

---

# Commit 3 - File Handling

The third version adds file handling.

The program can:

- Save expenses to a file
- Load saved expenses
- Keep expenses available after restarting the program

---

# Commit 4 - Exception Handling and Final Improvements

The final version adds:

- Exception handling
- Input validation
- Prevent invalid expense amounts
- Better menu structure
- Cleaner functions
- Improved expense management
