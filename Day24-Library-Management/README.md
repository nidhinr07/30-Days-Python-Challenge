# Day 24 - Library Management System 🐍

## Introduction

On the twenty-fourth day of my Python learning journey, I continued practicing Python by building a small **Library Management System**.

Instead of learning a new topic today, I focused on applying the concepts I have already learned to a practical program.

The project will be developed step by step through four commits.

---

# Project

## Library Management System

The program allows a user to manage books in a simple library.

The project will gradually include:

- Adding books
- Viewing books
- Searching for books
- Removing books
- File handling
- Exception handling
- Menu-driven program

---

# Commit 1 - Basic Library

The first version allows the user to:

- Add a book
- View all books
- Exit the program

Books are stored temporarily in a list.

---

# Commit 2 - Search and Remove

The second version adds:

- Search for a book
- Remove a book

The program becomes more interactive.

---

# Commit 3 - File Handling

The third version adds file handling.

The program can:

- Save books to a file
- Read books from a file
- Keep books available after the program is closed

---

# Commit 4 - Exception Handling and Final Improvements

The final version adds:

- Exception handling
- Better input validation
- Improved menu
- Cleaner functions
- Better user interaction
