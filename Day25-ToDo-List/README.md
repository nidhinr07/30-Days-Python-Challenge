# Day 25 - To-Do List Manager 📝

## Introduction

On the twenty-fifth day of my Python learning journey, I continued practicing Python by building a simple **To-Do List Manager**.

Instead of learning a new Python topic, I focused on applying the concepts I have already learned to a practical program.

The project will be developed step by step through four commits.

---

# Project

## To-Do List Manager

The program allows the user to manage a list of tasks.

The project will gradually include:

- Adding tasks
- Viewing tasks
- Completing tasks
- Deleting tasks
- File handling
- Exception handling
- Input validation
- Menu-driven programming

---

# Commit 1 - Basic To-Do List

The first version allows the user to:

- Add a task
- View tasks
- Exit the program

Tasks are stored temporarily in a list.

---

# Commit 2 - Complete and Delete Tasks

The second version adds:

- Mark a task as completed
- Delete a task

---

# Commit 3 - File Handling

The third version adds file handling.

The program can:

- Save tasks to a file
- Load saved tasks
- Keep tasks available after restarting the program

---

# Commit 4 - Exception Handling and Final Improvements

The final version adds:

- Exception handling
- Input validation
- Better menu structure
- Cleaner functions
- Improved task management
