On the twenty-eighth day of my Python learning journey, I practiced Python by building a simple **Rock Paper Scissors** game.

Instead of learning a new Python topic, I focused on applying the concepts I have already learned to an interactive game.

The game will be developed step by step through four commits.

---

# Game

## Rock Paper Scissors

The player chooses Rock, Paper, or Scissors.

The computer randomly chooses one of the three options.

The winner is decided using the following rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

- Choose Rock, Paper, or Scissors
