# Day 05 - Python Practice 📝

## Introduction

After learning Python fundamentals during the first four days, I practiced solving simple problems to strengthen my understanding of the concepts. These exercises combine multiple topics such as input, data types, string methods, conditional statements, loops, and functions.

## Practice Problems

### Problem 1 - User Information

Create a program that asks the user for their name and age. Display the entered information and print the data type of each value.

**Concepts Used:**

* Input
* Data Types
* Type Casting
* `type()` Function
* `print()`

---

### Problem 2 - Even or Odd

Create a function that accepts a number and checks whether it is even or odd using an `if-else` statement.

**Concepts Used:**

* User-defined Function
* Function Arguments
* `if-else`
* Return Statement

---

### Problem 3 - Number Pattern

Use a `for` loop and the `range()` function to print numbers from 1 to 10. Skip the number 5 using `continue` and stop the loop when the number becomes 9 using `break`.

**Concepts Used:**

* `for` Loop
* `range()`
* `break`
* `continue`

---

### Problem 4 - Student Result

Create a program that accepts a student's mark and displays the result using a `match-case` statement.

**Concepts Used:**

* User Input
* `match-case`
* Conditional Statements
