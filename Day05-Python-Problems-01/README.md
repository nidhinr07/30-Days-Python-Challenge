# Day 05 - Python Fundamentals Challenge 🧩

## Introduction

After learning Python fundamentals over the first four days, I completed a practice challenge that combines the concepts I have learned so far. Instead of focusing on a single topic, this challenge encourages the use of multiple Python concepts together to solve a real programming problem.

## Challenge

### Student Information System

Create a program that performs the following tasks:

1. Ask the user to enter their name, age, and marks.
2. Display the data entered by the user.
3. Display the data type of each input.
4. Convert the marks into an integer using type casting.
5. Display the length of the student's name.
6. Display the student's name in uppercase and title case.
7. Use an `if-else` statement to check whether the student has passed or failed.
8. Use a `match-case` statement to display the student's grade based on the following conditions:

   * A → Excellent
   * B → Good
   * C → Average
   * Any other value → Invalid Grade
9. Use a `for` loop with the `range()` function to print numbers from 1 to 5.
10. Use a `while` loop to display a countdown from 3 to 1.
11. Create a user-defined function that accepts the student's name and prints a welcome message.
12. Create another function that accepts the student's marks and returns whether the student has passed or failed.
