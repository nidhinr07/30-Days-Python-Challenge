# Day 05 - Python Fundamentals Challenge 🧩

## Introduction

After learning the core concepts of Python during the first four days, I completed a practice challenge to revise and strengthen my understanding. This challenge combines multiple beginner-level concepts into a single program.

## Challenge

### Student Information System

Create a simple Student Information System using Python.

The program should collect student details, perform basic string operations, display different data types, use conditional statements to determine the result and grade, demonstrate loops, and organize the program using user-defined functions.

## Concepts Practiced

* Print Statements
* User Input
* Data Types
* Type Casting
* String Methods
* `len()` Function
* `if-else`
* `match-case`
* `for` Loop
* `range()`
* `while` Loop
* `break`
* `continue`
* User-defined Functions
* Function Arguments
* Return Statement

## Goal

The goal of this challenge is to combine the Python concepts learned so far into one practical program and improve problem-solving skills through hands-on practice.
