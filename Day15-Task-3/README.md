# Day 15 - OOP Practice Questions 🧩

## Introduction

Day 15 is a practice day. These questions are based on the OOP concepts learned during Days 13 and 14.

The questions cover classes, objects, constructors, `self`, inheritance, access modifiers, getters, and setters.

---

## Question 01 - Student Class

Create a `Student` class with a constructor that accepts the student's name and age.

Create an object and display the student's details.

### Concepts

- Class
- Object
- Constructor
- `self`

---

## Question 02 - Bank Account

Create a `BankAccount` class with a private balance.

Create methods to:

- Get the balance
- Deposit money
- Update the balance using a setter

Create an object and perform these operations.

### Concepts

- Class
- Object
- Private variable
- Getter
- Setter

---

## Question 03 - Vehicle Inheritance

Create a parent class called `Vehicle` with a method called `start()`.

Create two child classes called `Car` and `Bike`.

Both classes should inherit from `Vehicle` and have their own methods.

Create objects and display their details.

### Concepts

- Class
- Object
- Inheritance
- Methods

---

## Question 04 - Employee Management

Create an `Employee` parent class with name, age, and salary.

Create `Developer` and `Manager` child classes.

Make salary private and use a getter and setter to access and update it.

Create objects for both employees and display their details.

### Concepts

- Class
- Object
- Constructor
- `self`
- Inheritance
- Private variable
- Getter
- Setter

---

## Goal

The goal of these questions is to practice the OOP concepts learned so far by solving small programming problems.
